স্টুডেন্ট পোর্টাল — Diploma in Engineering Exam-2025

ফাইল:
  index.html  = ছাত্রদের সার্চ পেইজ (সব তথ্য এর ভেতরেই)
  _headers    = নিরাপত্তা হেডার (Netlify / Cloudflare Pages স্বয়ংক্রিয়ভাবে ব্যবহার করে)
  robots.txt  = সার্চ ইঞ্জিন নিয়ন্ত্রণ

অনলাইনে দেওয়া:
  ১) Netlify: আগে netlify.com এ লগইন করুন (লগইন ছাড়া দিলে ১ ঘণ্টা পর সাইট মুছে যায়), তারপর app.netlify.com/drop এ এই ফোল্ডার টেনে ছাড়ুন।
     আপডেট: Sites -> আপনার সাইট -> Deploys পাতায় নতুন ফোল্ডার টেনে ছাড়ুন (লিংক একই থাকবে)।
  ২) GitHub: নতুন repository -> ফাইলগুলো আপলোড -> Settings -> Pages -> main / root -> Save.

ফলাফল বদলালে এডমিন সফটওয়্যার থেকে নতুন ZIP নিয়ে index.html আবার আপলোড করুন।
নিরাপত্তা: অ্যাকাউন্টে 2-Step Verification চালু রাখুন। এডমিন সফটওয়্যার অনলাইনে দেবেন না।
